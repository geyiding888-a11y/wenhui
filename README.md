# 文汇 · 材料汇总助手

一个帮高校行政人员**把各下属单位交上来的 Excel 自动拼成一张总表**的小工具。
总表出来之后，还能**直接打一句话问它**——不用再打开 Excel 一条条翻。

---

## 新版页面怎么用

- 双击「启动.bat」，进入绿色三栏工作台。
- 在右侧「上传资料」选择 Excel，再点「保存到收件箱」。同名文件会自动加编号，保留原文件。
- 中间点「开始汇总」，完成后下载总表和问题清单。
- 修改待确认的列名后点「保存我的确认」，系统会重新生成总表，请下载最新结果。
- **汇总跑完之后，中间会出现一个对话框，打一句人话就能问数据**（见第四节）。
- 左侧「我的资料库」查看资料来源，「汇总归档」下载历史结果，「设置与状态」检查 AI 连接。
- 没有配置 AI 密钥也能勾选「不花钱试跑」。这种模式仅按名称匹配，列名需要认真核对。
- 参考图中的 PDF/Word 检索、课程空间尚未实现。**「问数据」这一项已经做好了**（见第四节）。

## 一、这东西到底帮你省了什么

**你现在大概是这么干的：**

1. 发模板给下面各单位
2. 收回来一堆表，表头各不相同——有人写"单位"，有人写"所在学院"，有人写"二级单位"
3. 一个一个打开，**手工复制粘贴**到总表里，一边粘一边对齐列
4. 粘完发现有人的表有问题，再回头一个个核对、打电话问
5. 谁交了谁没交，靠翻聊天记录和邮件

**用了这个工具之后：**

1. 发模板给下面各单位（这一步省不掉）
2. 把收到的表**全部丢进「收件箱」文件夹**
3. 点一下按钮，去「输出」文件夹拿结果

中间那三步——对齐列、挑错、催人——都是它干。

具体来说它做四件事：

| 它做什么 | 具体点说 |
|---|---|
| **对齐列** | 看懂"单位 / 部门 / 所在学院 / 二级单位"其实是一回事，自动归到同一列 |
| **洗干净** | 全角空格、多打的空格、"1.2万"和"12000"、五花八门的日期写法，统一成一种 |
| **挑错** | 谁漏填了必填项、哪两行重复了、合计对不上——列成一张清单，精确到**哪个文件第几行** |
| **不敢确定的会问你** | 拿不准的地方标成黄色，绝不瞎猜。你点一下确认，它**记住**，下次同样表头自动就对 |

## 二、开始用：三步

### 第 1 步：注册 DeepSeek，拿到密钥

1. 打开 <https://platform.deepseek.com/>
2. 注册、登录
3. 左边菜单找到「API keys」，点「创建 API key」
4. **把弹出的那串字符复制下来**（形如 `sk-xxxxxxxxxxxx`）

> ⚠️ 这串密钥**只显示一次**，关掉窗口就再也看不到了。先复制到记事本放一会儿。
>
> ⚠️ 需要先充值才能用。充 **10 块钱**足够你跑很久（见下方"要花多少钱"）。

### 第 2 步：设置密钥

双击 **`设置密钥.bat`**。它会自动做三件事：

1. **自己从剪贴板里取密钥**——你刚才在网页上点了「复制」，密钥就在剪贴板里了。所以回到黑窗口**直接按回车就行，不用粘贴**。它会先把密钥打码显示给你确认一下（像 `sk-8281********`），按回车表示"就是这把"。
2. **问一下服务端这把密钥认不认**。认了才往下走。这一句很重要：如果密钥复制时少了几位、或者已经被作废，它会**当场**告诉你，而不是等你真正用的时候才发现"AI 用不了"却不知道哪儿错了。
3. 存好，提示你关窗口。

> 如果剪贴板里不是密钥（比如你中途复制了别的东西），它会让你手动粘贴。
> **粘贴的时候屏幕上什么都不会显示**——一个字、一个星号都没有。不是没粘上，
> 是故意藏起来的（防止被旁边的人看到），粘完直接按回车即可。

> Mac 用户双击 **`设置密钥.command`**。

设置完**关掉这个窗口**。

### 第 3 步：启动

双击 **`启动.bat`**（Mac 是 `启动.command`）。

第一次启动会花一两分钟装东西——**这是正常的，只慢这一次**。装完浏览器会自动打开一个网页，那就是工具界面。

> **Mac 用户注意**：第一次双击 `启动.command` 可能提示"无法打开，因为来自身份不明的开发者"。
> 这是苹果的安全机制。解决：**右键点它 → 选「打开」→ 再点「打开」**。只需做这一次。

## 三、日常怎么用

1. 打开 `收件箱` 文件夹，把收到的下级 Excel **全部拖进去**
2. （第一次用需要）打开 `模板` 文件夹，放一份**你期望的总表长什么样**的样表
3. 双击 `启动.bat`，浏览器里点「开始汇总」
4. 等一会儿。有黄标的地方点开确认一下
5. 去 `输出` 文件夹拿两个文件：
   - **`汇总表_日期.xlsx`** —— 拼好的总表，可以直接交上去
   - **`问题清单_日期.xlsx`** —— 哪份表哪里有问题，照着去问人就行

## 四、汇总跑完了，可以直接问它

**以前**：总表出来了，想知道"乙老师这学期要上多少课""指导学生最多的是谁"，
还是得自己打开 Excel，用筛选、用排序，一条条找。900 行翻起来很烦，而且每次都要重翻一遍。

**现在**：中间那个对话框里**打一句人话**就行。

### 怎么用

1. 先跑一次汇总（上面第三节）
2. 中间的对话框里打字，比如「乙老师这学期要上多少课？」
3. 按回车，等几秒。

第一次进去会给你三个例子，**点一下就自动填进去**，不用自己想该怎么问。

### 一个要紧的区别：它是**查**出来的，不是**猜**出来的

这是这个功能能不能信的关键。

| | 会发生什么 |
|---|---|
| **一般的 AI 聊天** | 你问它数字，它**凭印象编一个**。看着挺像真的，其实错的 |
| **这里** | 它把你的话翻译成一条**数据库查询**，由程序去总表里**真的查一遍**，再把查到的数字说给你听 |

所以答案跟你在 Excel 里筛出来的是**同一个数**，你可以自己核。

**它不知道的，它会说不知道。** 你问一个表里没有的人，它会回答"表里没有这个人"，
而不是随便编一个数糊弄你。这一条是特意教它的——**肯说不知道，这个功能才可信**。

### 它还能自己动手——但动手之前**一定先问你**

有时候它会说"要不我重新汇总一遍？"（比如你刚往收件箱里补了几个单位的表）。

**这时候它会停下来等你点头。** 屏幕上出现一张卡片，写着：

- 它**为什么**想重跑（原话给你看，比如"用户正在补交表格"）
- 这次**大概要花多少钱**（按你上次汇总的花费估的）
- 两个按钮：**「好，照做」** 和 **「先别动」**

| 你点 | 会发生什么 |
|---|---|
| 「好，照做」 | 它才真的重跑。跑完总表**自动换成新的** |
| 「先别动」 | 它什么都不做。表还是原来那张，然后接着跟你说话 |

> **为什么非要停下来问？** 因为重跑一次**又慢、又可能花钱、还会把你看的那张表换掉**。
> 这三件事都不该由它替你决定。
>
> 所以规矩是：**问数据（查一下）它直接做，不打扰你；动数据（重汇总）一定先问你。**

### 几个实打实的问题

**它会不会把总表改坏？**
不会。它手上的工具**只有"查"和"重跑"，没有"删"和"改"**。
而且"查"被程序死死限制成只能读——就算它（或者有人骗它）写出删表、改数据的命令，
也会**当场被拦下来**。

**它会不会一直转圈烧钱？**
不会。一次提问最多来回 6 轮（`config/settings.toml` 里的 `max_turns`），到了就收尾停下。

**问错了 / 想重来怎么办？**
对话框旁边有「重新开始对话」，点一下清掉聊天记录，从零开始。
**总表和你的数据不受任何影响。**

**一次提问多少钱？** 不到一分钱。实测一个问题 ¥0.002 ~ ¥0.006（详见第五节）。

## 五、重要：你的数据安全吗

你说表里有学生和老师的身份证号、手机号。这一条我们**专门做了处理**，请看清楚：

### 发给 AI 的，是**打了码**的内容

程序在把内容发给 DeepSeek 之前，会先把敏感信息变成这样：

| 原文 | 发给 AI 看到的样子 |
|---|---|
| `330102199001011234` | `3301**********1234` |
| `13812345678` | `138****5678` |
| `6222021234567890` | `************7890` |
| `zhangsan@example.com` | `z***@example.com` |

**为什么打了码还认得出来？** 因为 AI 在这套流程里只做一件事：**判断"这一列是什么意思"**。
它看的是列名，加上几个样本值的**形状**——"这是 18 位数字，像身份证"。
它不需要知道具体是谁。所以打码几乎不影响准确度，但真实的号码**从未离开这台电脑**。

### 你自己拿到的结果，是完整原文

打码**只作用于发给 AI 的那几个样本**。`输出` 文件夹里的汇总表，身份证号、手机号都是**完整的**，不影响你上报。

### 还有什么绝对不会外传

- ❌ 你的**完整表格数据**——只发"列名 + 每列 3~5 个样本值"，**不发整表**
- ❌ 你的**文件名、文件夹结构**
- ❌ 汇总结果、问题清单——这些只在你自己电脑上

### ⚠️ 但用了「问数」功能之后，多了一样东西会发出去：**真实姓名**

**这是这次新版最大的一个变化，必须说清楚，不能含糊过去。**

| | 模型看到的 |
|---|---|
| **以前（只跑汇总）** | "有这么一列叫『姓名』"，样本是 `张*`、`李*` |
| **现在（用了问数）** | 你问「张三有多少学生」时，**"张三"这三个字原样发出去**；查询命中的那些人，姓名也是真的 |

**为什么会变成这样？** 因为姓名打码了，这个问题就**永远答不出来**——
模型看到的是 `张*`，它没法知道你在问谁。而这个功能的价值一大半就在"问具体某个人"。
（另外，跑汇总对齐列名的时候本来就会把姓名样本发出去，所以这里并不是从"完全不发"变成了"发"。）

**具体发出去的是哪些东西：**

- ✅ 发：**你问的那句话** + **查询命中的那几行的真实姓名**（最多 20 行，不会发整张 900 行的表）
- ✅ **身份证号、手机号、银行卡号、邮箱，在发给 AI 的那一份里依然是打码的**——上面那四个开关照常生效
- ❌ 不发：你的总表、输出文件、问题清单、文件名、文件夹结构

**如果你介意，有两个开关**（都在 `config/settings.toml` 的 `[agent]` 下面，改完保存、重启程序生效）：

| 你想要 | 改哪一项 | 代价 |
|---|---|---|
| 姓名也打码 | `mask_name_in_answer = true` | 统计类问题（"指导学生最多的前十个人"）照样能答，但回答里的人名都变成 `张*`。**"张三有多少学生"这类问具体某人的问题，就答不了了** |
| 整个问答功能不要 | `enabled = false` | 对话框整块消失，其余功能照常。**汇总流水线完全不受影响** |

> 一句话：**要"能问具体某个人"，就得让 AI 看到姓名。这两件事没法兼得。**
> 选哪个由你定——默认按"能用"走，介意就改，改起来是一行的事。

### 一句话总结

| 你在做什么 | 发出去的 |
|---|---|
| **跑汇总** | 列名 + 几个**打码**样本。用来判断"这列是啥意思"。仅此而已 |
| **用问数** | 你问的那句话 + 查询命中的那几行（含**真实姓名**；身份证/手机号/银行卡/邮箱仍然打码） |

> 如果你的表格**涉及国家秘密**，那任何云端 AI 都不该用——请改用完全离线的方案，告诉我，我给你换。

## 六、要花多少钱

用的是 DeepSeek，按用量计费。当前价格大约是：

- 输入 **¥1 / 百万字**
- 输出 **¥2 / 百万字**

**你的场景实际花费**：一次汇总 20 份表，程序只发"列名 + 几个样本"，大约消耗几千字 —— **成本在几分钱量级**。

**汇总的三重保险，防止意外烧钱：**

1. 只发样本，**绝不发整表**
2. 同样的表头**只问一次**，之后走缓存（重复汇总同一个单位的表，不再花钱）
3. 设置里有**单次运行费用上限**（默认 5 元），超了自动停下问你

> 补充一句，免得你多花钱：**只有 AI 判断过的结果会被记住**。
> 你勾了「不花钱试跑」跑出来的那一次不算数，不会存进缓存——
> 不然你以后真想用 AI 的时候，程序会直接拿试跑的结果糊弄你。

### 问数（第四节那个对话框）要多少钱

**一次提问不到一分钱。** 实测一个问题 ¥0.002 ~ ¥0.006（已经算上它自己查了好几次）。

再省一点的两个开关，都在 `config/settings.toml` 的 `[agent]` 下面：

- 查出来的结果**最多只发 20 行**给 AI（`result_rows_for_ai`）。\
  它要"一共多少人"这种数字，本来的做法就是让它自己算 `SUM`/`COUNT`，
  所以给少**不影响准确度**，只省钱、也少往外发数据
- 一次提问最多来回 **6 轮**（`max_turns`），防止它转圈

**问答的花费单独记账**，不和汇总混在一起。侧边栏能一眼看到两笔账各花了多少：

```
汇总累计 ¥0.0130　·　问答累计 ¥0.0057　·　问过 3 次
```

**问答有自己的一份上限**（`[agent]` 下的 `cost_limit_cny`，默认 2 元，是**累计**的）。
到线了它就停下不再回答，并告诉你改哪里调大。

> **为什么不跟汇总共用一个上限？** 因为两者的花法完全不同：
> 汇总是"点一次花一笔"，一次几毛，你心里有数；
> 问答是"打一句话花一点"，一次几分钱，但**可以问一百次**。
> 共用一个额度的话，你会问着问着突然发现汇总跑不了了，
> 还说不清钱到底花在哪。

## 七、出问题了怎么办

### 先做这件事：双击 `验收.bat`

不管遇到什么问题，**先双击 `验收.bat`**（Mac 是 `验收.command`，第一次要右键 →「打开」）。

它做的事：把程序从头到尾自己跑一遍，**不联网、不花一分钱**。跑完最后一行显示"自检全部通过"，说明程序本身是好的，问题多半在密钥、网络或者某个具体的表格上；要是它自己就报错，那就把窗口里的内容发给我，别的先不用管。

它跑完**不会自己关窗口**，会停在 `Press any key to continue . . .` 等你按一下回车——这样你来得及看清内容。第一次跑要多等一会儿（它在装自检需要的小工具）。

### "还没有设置 API 密钥"

→ 你没做第二步。双击 `设置密钥.bat`。

### 设置完密钥，还是说没设置

→ 设置密钥后**必须关掉所有窗口重新打开**。Windows 的环境变量在已打开的窗口里不会更新。最省事的办法：重启电脑。

### 提示"余额不足" / "Insufficient Balance"

→ 去 <https://platform.deepseek.com/> 充值。

### 侧边栏显示「AI 现在用不了」

→ **先点一下红字下面的「重新检查一次」按钮。** 有时候只是刚才网络抖了一下，
重查就好了。

还不行的话，看它下面那句话，三种情况：

- **「自检失败：…没连上模型服务…」**（可能带 `WinError 10054`）：
  **十有八九是电脑上的代理软件（Clash、VPN 这类）把它拦了。**
  程序已经会自动让 API 域名不走代理，但如果还不行，
  把代理软件先退出，再双击 `启动.bat`。详见下面那条。
- **「密钥无效」**：密钥填错了或者被作废了。重新双击 `设置密钥.bat` 填一次。
- **「配置里写的模型…不存在」**：**模型又改名了**（已经改过两次）。它会同时把当前可用的名字列出来，照着改 `config/settings.toml` 里的 `model = "..."` 那一行即可。

> ⚠️ 这件事**必须当场处理**，不能拖。因为 AI 用不了的时候程序不会停下来，
> 它会**悄悄改用名称相似度**来对列名——结果是标黄特别多、对得也不准。
> 你要是不看侧边栏，只会觉得"这工具怎么这么笨"。

### 关于「代理软件把请求拦掉」这件事（重要）

这台电脑上装了 **Clash**，它会给系统设一个代理（`127.0.0.1:7890`）。
麻烦在于它的"不走代理名单"里**没有排除 DeepSeek 的域名**，
于是程序的请求被送进 Clash，Clash 再把一个**国内的** API 往国外节点上送，
节点直接把连接掐断——报错就是那句 `WinError 10054`。

**这个毛病很会骗人**：

- 它**不是每次必坏**，实测大约**一半概率**（6 次里坏 3 次）。
  于是现象变成"有时能用有时不能用"，很容易被当成网络抖动忍过去。
- 报错写的是"连不上"，但其实**是连上了又被掐断**。方向完全指错。

程序的处理：**自动把 DeepSeek 的域名加进"不走代理"名单**，
只影响这个程序，不改你的系统设置、也不动你的 Clash。

> 对应的开关在 `config/settings.toml` 里的 `bypass_proxy`，默认是 `true`。
> 什么时候改成 `false`：你的网络**必须**通过代理才能上外网的时候。

**为什么开发的时候没发现**：写代码的这台机器上，那个名单里恰好多了
DeepSeek 的域名，所以怎么试都是通的。差一点就当成"偶发网络问题"糊过去了。

> ⚠️ 这件事**必须当场处理**，不能拖。因为 AI 用不了的时候程序不会停下来，
> 它会**悄悄改用名称相似度**来对列名——结果是标黄特别多、对得也不准。
> 你要是不看侧边栏，只会觉得"这工具怎么这么笨"。

### 满屏都是黄的，是不是我的表有问题？

→ 先看侧边栏「AI 已就绪」是不是绿的。**十有八九是 AI 没调通**，不是你的表的问题。

如果 AI 是好的却仍然黄很多，那说明你的表列名确实跟标准表差得远——这时候把一份标准表放进 `模板` 文件夹，会明显变好。

### 双击 `启动.bat` 窗口一闪而过

→ **现在已经不会这样了**：不管成功失败，窗口都会停住等你按回车，不会自己关掉。

万一还是遇到（比如老版本的文件），说明出错了但没看清。**右键 `启动.bat` → 编辑**（或者用记事本打开），在**最后一行**加上 `pause`，保存后再双击，就能看到错误信息了。把错误发给我。

> 顺便解释一下这个"一闪而过"当初为什么会发生，因为它坑了我们挺久：
> 那三个双击用的 `.bat` 文件里原本写着中文（比如"正在准备…"）。
> 而 Windows 的黑窗口读这种文件时，**数的是"字数"而不是"字节数"**——
> 一个中文字占 3 个字节，于是它每读一行，位置就往前多跑一点点，
> 读到中间就串行了：某一行整个消失，下一行的尾巴被当成命令去执行，
> 屏幕上冒出一句 `'?─────┘' is not recognized as an internal or external command`。
>
> 修法很干脆：**`.bat` 里一个中文字都不留，全改成英文注释**，
> 中文统一搬到 `src/wenhui/launcher.py`（Python 处理中文是可靠的，不会错位）
> 和 `config` 下那两个 `.txt` 里。这样 Windows 和 Mac 的中文还合并成了一份，
> 改一处两边都变。

### 汇总出来的总表有列对错了

→ 打开 `config/settings.toml`，把 `confidence_threshold` 从 `0.75` **调高**到 `0.9`。这样它会更谨慎，更多地方标黄问你，而不是自己猜。

### 「待确认」里那几列，我确认了，下次怎么还问我？

→ 两种情况：

- **确认的是另一份表。** 「记住」是按**表头**记的。表头长得不一样，就是另一张表，得重新确认一次。
- **压根没点「保存我的确认」。** 光在下拉框里选了不算，要点下面那个按钮。

> 顺带说清楚一件事：拿不准的列**每次都会再问你一遍**，直到你确认。
> 这是故意的——程序宁可多问你几次，也不肯把"我没把握"偷偷变成"我确定"。

### 想推倒重来，让它忘掉学过的对应关系

→ 界面上点「状态」那一栏里的 **「全部忘掉，重新学」**。它会清空记住的所有对应关系，下次从头判断。哪次确认点错了，用这个。

### 某个文件读不出来

→ 常见原因：**文件正在 Excel 里开着**（先关掉）、文件有密码、或者是 `.xls` 老格式。老格式用 Excel 另存为 `.xlsx` 即可。

### 对话框没出现，或者是灰的

→ 三种可能，按顺序看：

1. **还没跑过汇总。** 对话框要有数据才能问。先在下面点「开始汇总」。
2. **没设置密钥。** 它会直接写"还没设置密钥，问答功能用不了"。
3. **设置里关掉了。** 看 `config/settings.toml` 的 `[agent]` 下面 `enabled` 是不是 `false`。

### 问它数据，它说"表里没有这个人"

→ 先确认**名字写法一模一样**。表里是"张小明"你打"张三"，它当然找不到。
也可以换个问法，比如「姓张的有几个人」。

> **这一条其实是好事**：它宁可说"表里没有"，也不肯编一个数糊弄你。
> 一个会说"我不知道"的助手才有用；一个每次都给你编一个数的助手，你会被它害了。

### 我打了字，它却回"上面那件事还没答复"

→ 上面那张卡片（"它想重新汇总，要不要？"）还等着你点。
**先点「好，照做」或者「先别动」**，然后才能接着问下一句。

这是故意的：不然它一边等你批准重跑、一边回答新问题，最后那个答案到底在答哪一句，谁都说不清。

### 点了「好，照做」，结果报错了

→ 看红字那句话。常见的是密钥没了、网络断了、或者问答花费到了上限。

**不管哪种，程序都会把那张卡片摘掉、把输入框还给你**，不会把你卡在"上面那件事还没答复"上出不来。

### 它好像"忘了"我刚才问过什么

→ 聊天记录**关掉程序就没了**（这是有意的，不在你电脑上留痕）。
同一个窗口里它会记得上下文，你可以接着追问「那李四呢」。

### 问答累计花费到了上限

→ 侧边栏会写清楚。改 `config/settings.toml` 的 `[agent]` 下面的 `cost_limit_cny`，
调大、或者设成 `0`（不限制），保存后重启程序。

## 八、为什么选这些技术（一句话一个）

你可能好奇为什么是这些东西。每个选择都只为了一个目的：**让它不容易坏**。

| 用了什么 | 一句话理由 |
|---|---|
| **Python** | 处理表格和接 AI 最成熟的 language，遇到问题网上能找到答案 |
| **LangChain** | 你指定的框架。汇总那边负责"把表格列名喂给 AI、拿回结构化结果"；问数那边负责"让 AI 自己决定查什么、并管住它不乱动" |
| **DeepSeek** | 国内直连不用翻墙、便宜、接口通用（将来想换通义/Kimi，改一行配置） |
| **Streamlit** | 界面部分——不用写网页代码，一个文件就是一个网页，Win/Mac 表现一致 |
| **SQLite** | 存"哪些表头问过 AI 了"，一个文件搞定，**不用装数据库** |
| **uv** | 自动装好正确的 Python 版本和依赖 |

## 十一、技术细节（不懂可以跳过）

<details>
<summary>点开看：给接手的技术人员</summary>

- 运行环境：uv 托管的 CPython 3.12（`.python-version` 锁定），依赖见 `pyproject.toml`
- 流水线：`reader` 探测表头 → `privacy` 脱敏 → `mapper`（LangChain 结构化输出做列语义对齐）→ `cleaner` 清洗 → `validator` 校验 → `writer` 输出
- AI 用法：`init_chat_model(model_provider="openai", base_url=...)` + `with_structured_output(Pydantic)`。
  **汇总流水线刻意不用 Agent**——它是一条固定流程，让模型自选下一步会导致结果不可复现、费用不可控。
  **这句话现在依然成立**：它反对的是"用 Agent 替掉流水线"，不是"不能有 Agent"。
  底下那条流水线（读表→脱敏→对齐→清洗→校验→出表）一个字都没改
- 问数助手（`src/wenhui/agent/`）：LangChain 1.4 的 `create_agent` + LangGraph，
  和流水线**并存但互不干涉**——它只站在总表上面做一个"会写 SQL 的查询员"。
  四道闸：
  ① `guard.install_readonly_guard` 用 `set_authorizer` 白名单，只放行
  `SQLITE_SELECT / READ / FUNCTION / TRANSACTION / RECURSIVE`——**按动作拒绝而不是按文本**，
  所以注释、大小写、`/* */`、多语句注入都绕不过去（字符串检查只当给模型的友善提示，不当安全边界）；
  ② 结果回传前过 `privacy.mask_text`；
  ③ `guard.arm_timeout` 用 `set_progress_handler` 掐掉跑不完的查询，防止焊死界面；
  ④ `HumanInTheLoopMiddleware` **只拦 `rerun_merge` 一个工具**，没登记的自动放行——
  这才是"只读自动、动手先问"。另加 `ModelCallLimitMiddleware` 防转圈烧钱。
  `guard.py` 另外两件事：`disable_dqs`（关掉 SQLite 的双引号当字符串的怪癖，
  否则 `WHERE "姓名"='张三'` 会静默返回错结果）和 `fix_identifier_quotes`（修单引号列名）
- **一个必须记住的取舍**：`mask_name_in_answer` 默认 `false`，即**查询结果里的真实姓名会发给模型**。
  不这样"张三有多少学生"就永远答不出来。开关和影响面见第五节
- 记账：agent 走 `client.model` 会绕过 `structured()` 里的计量，所以 `chat.py` 每轮调
  `LLMClient.record_usage(AIMessage)` 把 `usage_metadata` 捞回来补记——不补的话
  花费会一直是 0，而 README 承诺过费用可控。问答花费记在 `query_usage` 表
  （和 `runs` 分开），所以上限也分开设
- 中断/恢复：助手"停下来等你点头"用了 LangGraph 的 `interrupt`。Streamlit 每次交互
  会把整个脚本重跑一遍，**agent 对象每次都是新建的**——所以靠的是
  `checkpointer` + 固定 `THREAD_ID` 共享记忆，而不是把对象存在模块级变量里
- 结构化输出走 `_METHODS` 兜底链 `function_calling → json_mode → 默认`（顺序是实测出来的，
  见 `llm.py` 注释）。DeepSeek 目前**不支持**原生 `json_schema`（400），
  且 `deepseek-flash` 是思考模型，**思考模式下禁止强制 `tool_choice`**——
  所以 `disable_thinking = true` 是让强约束生效的前提，不是性能优化
- 缓存：列名签名 → 映射结果**及每列的把握程度**，存 SQLite（`data/wenhui.db`）。
  把握程度必须一起存：否则缓存命中时会把"上次没把握"的列当成"确定无疑"，
  那些列就再也不会请用户确认了（`map_sheet(cached_confidence=...)`）。
  规则兜底的结果**不缓存**——它免费且不算数，缓存只会堵死以后问 AI 的机会；
  打开库时会把老版本残留的 `source='rule'` 条目清掉（`Store._init`）
- 密钥：只从环境变量 `LLM_API_KEY` 读取（`config.py` 中 `API_KEY_ENV`）。
  **严禁写入任何文件**，`.env.example` 里只有变量名
- 降级：LLM 调用失败或 JSON 解析失败 → 退回规则匹配并标记"待确认"，流水线不中断
- 已知变更（名字变过两次，别写死）：
  `deepseek-chat` 于 2026-07-24 下线 → `deepseek-v4-flash` 于 2026-09-14 发现也已改名 → 现用 `deepseek-flash`。
  启动自检会调 `/v1/models` 列出当前账号下可用的名字，名字再变时改 `config/settings.toml` 一行即可

</details>
